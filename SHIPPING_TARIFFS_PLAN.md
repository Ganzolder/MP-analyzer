# 📦 План загрузки тарифов перевозки в БД

## 📋 Задача

Загрузить файл с тарифами перевозки (35000 строк) в базу данных для использования в калькуляторе.

---

## 🔍 Что нужно узнать

Перед началом работы нужно понять структуру файла:

1. **Формат файла:**
   - Excel (.xlsx, .xls)?
   - CSV?
   - Другой формат?

2. **Структура данных (колонки):**
   - Регион отправления?
   - Регион назначения?
   - Вес (диапазон или точное значение)?
   - Габариты (длина, ширина, высота)?
   - Тип доставки (обычная, экспресс)?
   - Стоимость доставки?
   - Дополнительные параметры?

3. **Логика расчёта:**
   - Как калькулятор должен искать тариф?
   - По весу?
   - По габаритам?
   - По региону?
   - Комбинация параметров?

## 🗄️ Предполагаемая структура БД

### Модель ShippingTariff

```prisma
model ShippingTariff {
  id              String   @id @default(cuid())
  
  // Параметры доставки
  fromRegion      String?  // Регион отправления
  toRegion        String?  // Регион назначения
  deliveryType    String?  // Тип доставки (standard, express, etc)
  
  // Весовые параметры
  weightMin       Float?   // Минимальный вес (г)
  weightMax       Float?   // Максимальный вес (г)
  
  // Габариты
  lengthMin       Float?   // Минимальная длина (мм)
  lengthMax       Float?   // Максимальная длина (мм)
  widthMin        Float?   // Минимальная ширина (мм)
  widthMax        Float?   // Максимальная ширина (мм)
  heightMin       Float?   // Минимальная высота (мм)
  heightMax       Float?   // Максимальная высота (мм)
  
  // Стоимость
  basePrice       Float    // Базовая стоимость
  pricePerKg      Float?   // Стоимость за кг (если применимо)
  pricePerVolume  Float?   // Стоимость за объём (если применимо)
  
  // Дополнительные параметры
  marketplace     String?  // Маркетплейс (ozon, wildberries, yandex-market)
  category        String?  // Категория товара
  notes           String?  // Примечания
  
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
  
  @@index([marketplace, fromRegion, toRegion])
  @@index([weightMin, weightMax])
  @@index([deliveryType])
}
```

## ⚡ Оптимизация для больших файлов

Для файла на 35000 строк:

1. **Batch insert** — вставлять по 1000 записей за раз
2. **Транзакции** — использовать транзакции для целостности
3. **Прогресс** — показывать прогресс загрузки
4. **Индексы** — создать индексы для быстрого поиска
5. **Обработка ошибок** — продолжать загрузку при ошибках в отдельных строках
