# Лимиты API для AI-анализа

## Текущий провайдер: Google Gemini 2.0 Flash

### Конфигурация в проекте

```typescript
{
  model: "gemini-2.0-flash-exp",
  maxTokens: 8192,  // Максимум токенов в ответе
  temperature: 0.7,
  apiKeyEnv: "GOOGLE_GENERATIVE_AI_API_KEY"
}
```

## Лимиты Google Gemini API

### 1. Контекстное окно (Input + Output)

- **Gemini 2.0 Flash Experimental**: до **1,000,000 токенов** контекста
- Это включает:
  - Системный промпт (~500 токенов)
  - Пользовательский промпт с данными (может быть очень большим)
  - Генерируемый ответ (до 8192 токенов по настройке)

### 2. Максимум токенов в ответе (Output)

- **Текущая настройка**: `maxTokens: 8192`
- Это максимальное количество токенов, которое AI может сгенерировать в ответе
- Можно увеличить до 32,768 токенов для Gemini 2.0 Flash

### 3. Rate Limits (лимиты скорости запросов)

Google Gemini API имеет следующие лимиты:

#### Бесплатный тариф (Tier 1):
- **Requests per minute (RPM)**: 15 запросов в минуту
- **Tokens per minute (TPM)**: 1,000,000 токенов в минуту
- **Requests per day (RPD)**: 1,500 запросов в день

#### Платный тариф (Tier 2+):
- **Requests per minute (RPM)**: 360 запросов в минуту
- **Tokens per minute (TPM)**: 2,000,000+ токенов в минуту
- **Requests per day (RPD)**: без ограничений (зависит от тарифа)

### 4. Квоты по умолчанию

При первом использовании Google Gemini API:
- Начальная квота: обычно 15 RPM, 1M TPM
- После верификации и использования: может быть увеличена автоматически
- Для увеличения квот: обратитесь в Google Cloud Console

## Оценка размера запросов в проекте

### Типичный запрос для анализа отчёта:

1. **Системный промпт**: ~500 токенов
2. **Пользовательский промпт**: 
   - Summary: ~100 токенов
   - Top Products (10 товаров): ~200 токенов
   - All Products (все товары): может быть 5,000-50,000+ токенов
   - Problems: ~300 токенов
   - Cost Breakdown: ~100 токенов
   - Orders (все заказы): может быть 10,000-100,000+ токенов
   - Charge Type Breakdown: ~500 токенов
   - Daily Metrics: ~1,000 токенов
   - **Итого**: от ~2,000 до 150,000+ токенов в зависимости от размера отчёта

3. **Ответ AI**: до 8,192 токенов (по настройке)

### Примеры размеров запросов:

| Раздел | Товары | Заказы | Размер запроса (токены) |
|--------|--------|--------|-------------------------|
| Обзор | 10 | - | ~2,000-3,000 |
| Товары | Все (500+) | - | ~10,000-50,000 |
| Заказы | - | Все (1000+) | ~20,000-100,000 |
| Себестоимость | Все | Все | ~30,000-150,000 |

## Рекомендации

### ✅ Что работает хорошо:

1. **Обзор** - небольшой размер запроса, укладывается в лимиты
2. **Начисления** - средний размер, обычно без проблем
3. **Проблемы** - небольшой размер запроса

### ⚠️ Потенциальные проблемы:

1. **Товары** - при большом количестве товаров (500+) запрос может быть очень большим
2. **Заказы** - при большом количестве заказов (1000+) запрос может превысить разумные размеры
3. **Себестоимость** - комбинация товаров и заказов может создать очень большой запрос

### 💡 Оптимизация (если нужна):

Если возникают проблемы с лимитами:

1. **Уменьшить maxTokens в ответе** (если не нужен длинный ответ):
   ```typescript
   maxTokens: 4096  // вместо 8192
   ```

2. **Вернуть ограничения на количество данных**:
   - Товары: максимум 200-500
   - Заказы: максимум 500-1000

3. **Разбить анализ на части**:
   - Анализировать товары по категориям
   - Анализировать заказы по периодам

4. **Использовать более мощный тариф**:
   - Перейти на платный тариф Google Gemini для увеличения лимитов

## Мониторинг использования

### Как проверить текущие лимиты:

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com)
2. Выберите проект с Gemini API
3. Перейдите в "APIs & Services" → "Quotas"
4. Найдите "Generative Language API"
5. Проверьте текущие лимиты и использование

### Ошибки при превышении лимитов:

- **429 Too Many Requests**: Превышен лимит RPM (запросов в минуту)
- **429 Resource Exhausted**: Превышен лимит TPM (токенов в минуту)
- **400 Bad Request**: Превышен лимит контекста (1M токенов)
