## Быстрый старт

Если вы только начинаете работать с проектом:

1. Прочитайте **[00-PROJECT-OVERVIEW.md](./00-PROJECT-OVERVIEW.md)** для понимания общей картины
2. Изучите **[01-FILE-STRUCTURE.md](./01-FILE-STRUCTURE.md)** чтобы понять структуру проекта
3. Ознакомьтесь с **[02-ARCHITECTURE.md](./02-ARCHITECTURE.md)** для понимания принципов работы
4. Используйте **[03-API.md](./03-API.md)** как справочник при работе с API
5. Следуйте **[04-DEVELOPMENT.md](./04-DEVELOPMENT.md)** при разработке новых функций
