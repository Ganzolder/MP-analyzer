# 📊 Ozon Analyzer - Обзор проекта

## Назначение проекта

**Ozon Analyzer** - веб-приложение для анализа финансовых отчётов Ozon селлеров. Позволяет загружать XLS/XLSX файлы с начислениями и получать детальную аналитику, графики и AI-рекомендации для роста бизнеса.

## Текущее состояние проекта

### ✅ Реализовано (MVP)

1. **Загрузка файлов**
   - Drag-and-drop интерфейс
   - Поддержка множественных файлов (объединение отчётов)
   - Поддержка файла себестоимости (опционально)
   - Валидация формата и размера

2. **Парсинг Excel файлов**
   - Поддержка XLS и XLSX форматов
   - Декодирование специфичных кодировок Ozon (KOI-7, UTF-16LE)
   - Извлечение данных о заказах, начислениях, товарах

3. **Анализ данных**
   - Агрегация заказов по номерам
   - Расчёт метрик по товарам (выручка, прибыль, маржа)
   - Расчёт сводных показателей (общая выручка, чистая прибыль, количество заказов)
   - Анализ затрат по категориям
   - Метрики по дням
   - Статистика по схемам доставки
   - Детализация по типам начислений

4. **Визуализация**
   - Интерактивные графики (Recharts)
   - Таблицы с данными
   - Экспорт в PDF и XLSX

5. **Исключение товаров**
   - Возможность исключать товары из анализа по SKU
   - Пересчёт всех метрик с учётом исключений
   - Возврат исключённых товаров

6. **AI анализ** (частично)
   - Интеграция с OpenAI, Anthropic, Google
   - Генерация рекомендаций на основе данных
   - Кастомные промпты

### 🚧 В разработке

- Авторизация пользователей (NextAuth.js)
- История отчётов в БД
- Система подписок
- Полная интеграция Python сервиса

### 📋 Планируется

- Сравнение периодов
- База себестоимости товаров
- Расширенная аналитика

## Технологический стек

### Frontend
- **Framework:** Next.js 14+ (App Router)
- **UI:** React 18, TypeScript 5.3
- **Стили:** Tailwind CSS 3.4
- **Компоненты:** Radix UI (shadcn/ui)
- **Анимации:** Framer Motion
- **Графики:** Recharts
- **State Management:** Zustand
- **Форматирование:** date-fns, Intl

### Backend
- **API:** Next.js API Routes
- **БД:** Prisma + SQLite (dev) / PostgreSQL (prod)
- **Парсинг Excel:** xlsx, exceljs, iconv-lite
- **AI:** @ai-sdk/openai, @ai-sdk/anthropic, @ai-sdk/google

### Инфраструктура
- **Деплой:** Vercel
- **Python сервис:** FastAPI (опционально, не используется активно)

## Архитектура приложения

### Поток данных

```
1. Загрузка файла(ов) → app/page.tsx
   ↓
2. Отправка на сервер → POST /api/analyze
   ↓
3. Парсинг файла → lib/analysis/parsers/file-parser.ts
   ↓
4. Агрегация заказов → lib/analysis/aggregators/order-aggregator.ts
   ↓
5. Расчёт метрик → lib/analysis/calculators/*
   ↓
6. Генерация результата → lib/analysis/analyzer.ts
   ↓
7. Сохранение в store → lib/store/analysis-store.ts
   ↓
8. Отображение → app/analysis/[id]/page.tsx
```

### Основные модули

- **lib/analysis/** - ядро анализа данных
- **app/api/** - API endpoints
- **components/** - React компоненты
- **lib/store/** - Zustand stores
- **prisma/** - схема базы данных
