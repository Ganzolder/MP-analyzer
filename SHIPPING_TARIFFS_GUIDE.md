# 📦 Руководство по загрузке тарифов перевозки

## ✅ Что уже готово

1. **Модель БД** — `ShippingTariff` в Prisma schema
2. **API endpoints:**
   - `POST /api/shipping-tariffs/upload` — загрузка файла
   - `POST /api/shipping-tariffs/search` — поиск тарифа
3. **Сервис расчёта** — `lib/calculator/services/shipping-calculator.ts`

---

## 📋 Шаг 1: Применить миграцию БД

Создайте таблицу в базе данных:

```bash
npx prisma migrate dev --name add_shipping_tariffs
```

Или для production:

```bash
npx prisma migrate deploy
```

## 📋 Шаг 2: Подготовить файл с тарифами

### Ожидаемые колонки (гибкий поиск по названиям):

**Обязательные:**
- **Базовая стоимость** — колонка с названием: "базовая стоимость", "baseprice", "стоимость", "цена", "price", "тариф"

**Опциональные (будут найдены автоматически):**
- **Маркетплейс** — "маркетплейс", "marketplace", "площадка"
- **Регион отправления** — "регион отправления", "откуда", "from", "fromregion"
- **Регион назначения** — "регион назначения", "куда", "to", "toregion"
- **Город отправления** — "город отправления", "город от", "fromcity"
- **Город назначения** — "город назначения", "город до", "tocity"
- **Тип доставки** — "тип доставки", "deliverytype", "доставка"
- **Метод доставки** — "метод доставки", "deliverymethod", "fbo", "fbs"
- **Вес мин/макс** — "вес мин", "вес от", "weightmin", "вес макс", "вес до", "weightmax"
- **Габариты мин/макс** — "длина мин", "ширина мин", "высота мин" и т.д.
- **Цена за кг** — "цена за кг", "priceperkg", "за кг", "руб/кг"
- **Цена за объём** — "цена за объём", "pricepervolume", "за объём", "руб/см³"
- **Категория** — "категория", "category"
- **Приоритет** — "приоритет", "priority"

|-------------|-------------------|-------------------|-------------|--------------|-------------------|------------|

## 📋 Шаг 3: Загрузить файл

### Вариант 1: Через API (рекомендуется)

Используйте curl или Postman:

```bash
curl -X POST https://your-app.vercel.app/api/shipping-tariffs/upload \
  -F "file=@path/to/your/tariffs.xlsx"
```

### Вариант 2: Через код (для тестирования)

Создайте скрипт `scripts/upload-tariffs.ts`:

```typescript
import * as fs from "fs";
import * as FormData from "form-data";

const filePath = "path/to/your/tariffs.xlsx";
const file = fs.createReadStream(filePath);

const formData = new FormData();
formData.append("file", file);

fetch("http://localhost:3000/api/shipping-tariffs/upload", {
  method: "POST",
  body: formData,
})
  .then(res => res.json())
  .then(data => console.log(data));
```

## 📋 Шаг 4: Использовать в калькуляторе

### Пример использования:

```typescript
import { getShippingCost } from "@/lib/calculator/services/shipping-calculator";

// Расчёт стоимости доставки для товара
const shippingCost = await getShippingCost({
  marketplace: "ozon",
  fromRegion: "Москва",
  toRegion: "Санкт-Петербург",
  weight: 1500, // граммы
  length: 300,  // мм
  width: 200,   // мм
  height: 100,  // мм
  deliveryType: "standard",
});

if (shippingCost) {
  console.log("Стоимость доставки:", shippingCost.totalCost, "₽");
  console.log("Детали:", shippingCost.calculationDetails);
}
```

## 🔍 Поиск тарифа через API

```bash
curl -X POST https://your-app.vercel.app/api/shipping-tariffs/search \
  -H "Content-Type: application/json" \
  -d '{
    "marketplace": "ozon",
    "fromRegion": "Москва",
    "toRegion": "Санкт-Петербург",
    "weight": 1500,
    "length": 300,
    "width": 200,
    "height": 100
  }'
```

## ⚙️ Логика поиска тарифа

1. **Фильтрация по параметрам:**
   - Маркетплейс (обязательно)
   - Регионы (если указаны)
   - Тип доставки (если указан)
   - Вес (проверка диапазона)
   - Габариты (проверка диапазонов)

2. **Сортировка:**
   - По приоритету (высший приоритет = выше)
   - По дате создания (новые = выше)

3. **Расчёт стоимости:**
   - Базовая стоимость
   - + Стоимость за вес (если указана)
   - + Стоимость за объём (если указана)
   - + Стоимость за расстояние (если указана)
   - Применение мин/макс ограничений

## 📊 Оптимизация для больших файлов

Для файла на 35000 строк:

- ✅ Batch insert (по 1000 записей)
- ✅ Транзакции для целостности
- ✅ Пропуск дубликатов (`skipDuplicates: true`)
- ✅ Индексы для быстрого поиска
- ✅ Обработка ошибок по строкам

**Ожидаемое время загрузки:** 2-5 минут для 35000 строк
