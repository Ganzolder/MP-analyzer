# Системный промпт для AI-анализа отчётов Ozon

## 📋 Описание

Этот документ содержит системный промпт, используемый для AI-анализа финансовых отчётов селлеров Ozon. Промпт настраивает AI-модель (Google Gemini) на роль эксперта по аналитике маркетплейсов и задаёт контекст для генерации рекомендаций.

---

## 🎯 Системный промпт (ANALYSIS_SYSTEM_PROMPT)

```
Ты - эксперт по аналитике маркетплейсов с опытом работы с Ozon. 
Твоя задача - анализировать финансовые отчёты селлеров и давать практичные рекомендации.

При анализе учитывай:
1. Маржинальность товаров и категорий
2. Процент отмен и возвратов
3. Структуру затрат (комиссии, логистика, реклама)
4. Сезонность и тренды продаж
5. Проблемные товары (убыточные, с высоким % возвратов)

Давай конкретные, actionable рекомендации с ожидаемым эффектом.
Приоритизируй рекомендации по потенциальному влиянию на прибыль.
Используй цифры и проценты для обоснования.
```

---

## 📝 Шаблон пользовательского промпта (buildAnalysisPrompt)

### Основной шаблон:

```
Проанализируй следующие данные отчёта Ozon:

{JSON.stringify(analysisData, null, 2)}

Дай 5-7 конкретных рекомендаций по улучшению показателей бизнеса.
Для каждой рекомендации укажи:
- Категорию (strategy/pricing/assortment/logistics/problems)
- Приоритет (high/medium/low)
- Ожидаемый эффект
- Конкретные шаги для внедрения
```

### С пользовательскими инструкциями:

Если пользователь указал дополнительные инструкции (customPrompt), они добавляются в конец промпта:

```
Дополнительные инструкции от пользователя:
{customPrompt}
```

## 📊 Структура данных, передаваемых в AI

### 1. Summary (Сводка метрик)

```json
{
  "summary": {
    "totalRevenue": 1000000,      // Общая выручка (гrossRevenue)
    "netPayout": 800000,          // Итого начислено (netPayout)
    "totalOrders": 1000,          // Всего заказов
    "completedOrders": 950,       // Завершённых заказов
    "returnedOrders": 50,         // Возвратов
    "returnRate": 5.0,            // Процент возвратов (%)
    "feesPercent": 20.0           // Процент удержаний (%)
  }
}
```

### 2. Top Products (Топ-10 товаров)

```json
{
  "topProducts": [
    {
      "sku": "12345",
      "name": "Название товара",
      "revenue": 10000,           // Выручка по товару
      "profit": 5000,             // Прибыль по товару
      "profitMargin": 50,         // Маржинальность (%)
      "returnRate": 2.0           // Процент возвратов (%)
    },
    // ... до 10 товаров
  ]
}
```

### 3. Problems (Проблемные зоны)

```json
{
  "problems": [
    {
      "type": "low_margin",       // Тип проблемы
      "severity": "medium",       // Серьёзность (low/medium/high/critical)
      "description": "Описание проблемы",
      "affectedItems": ["SKU1", "SKU2"] // Затронутые товары/заказы
    },
    // ... другие проблемы
  ]
}
```

### 4. Cost Breakdown (Разбивка затрат)

```json
{
  "costBreakdown": {
    "commission": 150000,         // Комиссии Ozon
    "logistics": 50000,           // Логистика
    "returns": 25000,             // Обработка возвратов
    "storage": 10000,             // Хранение
    "advertising": 30000,         // Реклама
    "penalties": 5000             // Штрафы
  }
}
```

## 🔧 Параметры AI-запроса

### Конфигурация Google Gemini:

- **Модель**: `gemini-2.0-flash-exp`
- **maxTokens**: `8192`
- **temperature**: `0.7`
- **Провайдер**: `google` (Google Gemini)
- **API ключ**: `GOOGLE_GENERATIVE_AI_API_KEY`

### Альтернативные провайдеры:

- **z.ai GLM-4.7**: `glm-4.7` (maxTokens: 4096, temperature: 0.7)
- **OpenAI GPT-4**: `gpt-4-turbo-preview` (maxTokens: 4096, temperature: 0.7)
- **Anthropic Claude**: `claude-3-opus-20240229` (maxTokens: 4096, temperature: 0.7)

## 🔄 Как изменить промпт

### Изменить системный промпт:

1. Откройте `lib/config/ai-providers.ts`
2. Найдите переменную `ANALYSIS_SYSTEM_PROMPT`
3. Измените текст промпта
4. Перезапустите сервер

### Изменить шаблон промпта:

1. Откройте `lib/config/ai-providers.ts`
2. Найдите функцию `buildAnalysisPrompt()`
3. Измените структуру промпта
4. Перезапустите сервер

## ✅ Требования к ответу AI

AI должен возвращать рекомендации в следующем формате:

### Структура рекомендации:

- **id**: Уникальный идентификатор
- **type**: Категория (strategy/pricing/assortment/logistics/problems)
- **priority**: Приоритет (high/medium/low)
- **title**: Заголовок рекомендации
- **description**: Описание проблемы/рекомендации
- **impact**: Ожидаемый эффект
- **actions**: Массив конкретных шагов для внедрения

### Пример ответа:

```json
{
  "recommendations": [
    {
      "id": "rec_1",
      "type": "pricing",
      "priority": "high",
      "title": "Увеличить цену на товары с низкой маржой",
      "description": "Товары с маржой ниже 20% снижают общую прибыльность",
      "impact": "Увеличение общей прибыли на 15-20%",
      "actions": [
        "Проанализировать конкурентов",
        "Повысить цены на 5-10%",
        "Мониторить продажи после изменения"
      ]
    }
  ],
  "insights": "Краткое резюме анализа",
  "summary": "Итоговое заключение"
}
```
