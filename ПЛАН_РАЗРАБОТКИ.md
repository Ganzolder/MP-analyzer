  - [ ] `/api/analysis/[id]` — проверять доступ к отчёту

  - [ ] Пользователи видят только свои отчёты

  - [ ] Показывать только отчёты текущего пользователя
  - [ ] Добавить проверку авторизации
- [ ] Тестирование:
  - [ ] Вход через Google
  - [ ] Вход через Yandex
  - [ ] Вход через телефон
  - [ ] Проверка изоляции данных (пользователь видит только свои отчёты)

#### Технические детали:

**NextAuth v5 (Auth.js):**
- Использовать уже установленный `next-auth@5.0.0-beta.4`
- Адаптер: `@auth/prisma-adapter` для работы с Prisma
- Сессии через httpOnly cookies

**Google OAuth:**
- Регистрация в [Google Cloud Console](https://console.cloud.google.com/)
- Создать OAuth 2.0 credentials
- Redirect URI: `https://your-app.vercel.app/api/auth/callback/google`

**Yandex OAuth:**
- Регистрация в [Yandex OAuth](https://oauth.yandex.ru/)
- Создать приложение
- Redirect URI: `https://your-app.vercel.app/api/auth/callback/yandex`

**SMS авторизация:**
- Вариант 1: Twilio (международный, платный)
- Вариант 2: SMS.ru (российский, есть бесплатный тариф)
- Вариант 3: Yandex SMS (если уже используем Yandex)
- Логика:
  1. Пользователь вводит номер телефона
  2. Отправляется SMS с кодом
  3. Пользователь вводит код
  4. Создаётся/находится пользователь в БД
  5. Создаётся сессия

**Структура БД:**
- Модель `User` уже есть в схеме
- Поле `phone` нужно добавить (опционально)
- Связь `Report.userId` уже есть

#### Оценка времени:
- Google OAuth: 1-2 часа
- Yandex OAuth: 1-2 часа
- SMS авторизация: 3-4 часа
- **Итого: 5-8 часов**
