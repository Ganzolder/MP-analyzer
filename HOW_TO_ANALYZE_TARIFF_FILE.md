# 🔍 Как проанализировать файл с тарифами

## Проблема

Я создал универсальную структуру для загрузки тарифов, но не знаю структуру вашего файла. Нужно проанализировать файл, чтобы настроить парсер правильно.

---

## ✅ Решение: Скрипт анализа

Создан скрипт, который проанализирует ваш файл и покажет:
- Какие колонки есть
- Примеры данных
- Типы данных
- Статистику заполненности

---

## 📋 Как использовать

### Шаг 1: Запустите скрипт анализа

```bash
node scripts/analyze-tariff-file.js "путь/к/вашему/файлу.xlsx"
```

**Пример:**
```bash
node scripts/analyze-tariff-file.js "База/тарифы.xlsx"
```

### Шаг 2: Посмотрите результат

Скрипт выведет в консоль:
- Список всех колонок
- Примеры данных (первые 5 строк)
- Типы данных в каждой колонке
- Статистику заполненности

Также создаст файл `tariff-file-analysis.json` с полной информацией.

---

## 📤 Что сделать дальше

После запуска скрипта:

1. **Скопируйте вывод** из консоли
2. **Или отправьте файл** `tariff-file-analysis.json`
3. **Или покажите скриншот** структуры файла

Мне нужно увидеть:
- Какие колонки есть в файле
- Примеры данных
- Как определяются тарифы (по каким параметрам)

---

## 🔄 Альтернатива: Покажите структуру вручную

Если не можете запустить скрипт, просто покажите:

1. **Скриншот** файла (первые несколько строк)
2. **Или опишите колонки:**
   - Какие колонки есть?
   - Что в них хранится?
   - Как определяется тариф?

---

## 💡 Что я сделаю после анализа

1. **Настрою парсер** под вашу структуру
2. **Обновлю модель БД** (если нужны дополнительные поля)
3. **Настрою логику поиска** тарифов
4. **Протестирую загрузку** на вашем файле

---

## 🚀 Быстрый старт

1. Найдите файл с тарифами
2. Запустите: `node scripts/analyze-tariff-file.js "путь/к/файлу.xlsx"`
3. Отправьте результат

Или просто покажите структуру файла, и я настрою всё под неё!
