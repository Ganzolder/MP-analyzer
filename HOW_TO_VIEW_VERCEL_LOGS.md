# 📊 Как посмотреть логи в Vercel Dashboard

## 🎯 Способ 1: Через Deployments (рекомендуется)

### Шаг 1: Откройте Vercel Dashboard
1. Перейдите на https://vercel.com
2. Войдите в аккаунт
3. Выберите ваш проект

### Шаг 2: Откройте Deployments
1. В левом меню нажмите **"Deployments"** (или "Деплои")
2. Вы увидите список всех деплоев
3. Найдите последний деплой (самый верхний в списке)
4. Нажмите на него

### Шаг 3: Откройте Logs
1. В открывшемся окне деплоя найдите вкладку **"Logs"** (или "Логи")
2. Нажмите на неё
3. Вы увидите все логи выполнения

### Шаг 4: Фильтрация логов
- В логах ищите строки с `[API]` — это логи из API routes
- Ищите строки с `💾`, `✅`, `❌` — это наши маркеры
- Используйте поиск (Ctrl+F / Cmd+F) для поиска по ключевым словам:
  - `сохранение в БД`
  - `ОШИБКА`
  - `DATABASE_URL`

---

## 🎯 Способ 2: Через Functions (альтернативный)

### Шаг 1: Откройте проект
1. Vercel Dashboard → выберите проект

### Шаг 2: Откройте Settings
1. В верхнем меню нажмите **"Settings"** (или "Настройки")

### Шаг 3: Откройте Functions
1. В левом меню Settings найдите **"Functions"**
2. Нажмите на неё
3. Вы увидите список всех функций

### Шаг 4: Найдите функцию analyze
1. В списке функций найдите `/api/analyze`
2. Нажмите на неё
3. Откроются логи этой функции

---

## 🎯 Способ 3: Через Real-time Logs (для активных запросов)

### Шаг 1: Откройте проект
1. Vercel Dashboard → выберите проект

### Шаг 2: Откройте Analytics
1. В верхнем меню нажмите **"Analytics"** (или "Аналитика")
2. Или в левом меню найдите **"Logs"** / **"Real-time Logs"**

### Шаг 3: Смотрите логи в реальном времени
1. Логи будут обновляться автоматически
2. Вы увидите все запросы к API в реальном времени

---

## 🔍 Что искать в логах

### При успешном сохранении:
```
💾 [API] Попытка сохранения в БД...
   DATABASE_URL: ✅ Настроен
   Analysis ID: clx...
   File name: отчет.xlsx
✅ [API] Результат сохранён в БД: clx...
   Report ID: clx...
   Created at: 2025-01-...
```

### При ошибке:
```
💾 [API] Попытка сохранения в БД...
   DATABASE_URL: ❌ НЕ НАСТРОЕН  <-- ПРОБЛЕМА!
```

Или:
```
❌ [API] ОШИБКА при сохранении в БД:
   Сообщение: Can't reach database server
   Код: P1001
   Детали: ...
```

## 📱 Альтернатива: Локальные логи

Если у вас запущен локальный сервер:

1. Откройте терминал, где запущен `npm run dev`
2. Все логи будут выводиться прямо в терминал
3. Ищите те же маркеры: `💾`, `✅`, `❌`

## 🛠️ Если не можете найти логи

### Вариант 1: Проверьте через API endpoint

Откройте в браузере:
```
https://your-app.vercel.app/api/health/db
```

Это покажет статус подключения к БД без необходимости смотреть логи.

### Вариант 2: Добавьте временный endpoint для отладки

Создайте файл `app/api/debug/route.ts`:

```typescript
import { NextRequest, NextResponse } from "next/server";

export async function GET(request: NextRequest) {
  return NextResponse.json({
    databaseUrl: process.env.DATABASE_URL ? "✅ Настроен" : "❌ НЕ НАСТРОЕН",
    nodeEnv: process.env.NODE_ENV,
    timestamp: new Date().toISOString(),
  });
}
```

Затем откройте:
```
https://your-app.vercel.app/api/debug
```

Это покажет, настроен ли DATABASE_URL.

## 💡 Совет

**Самый простой способ:**
1. Откройте Vercel Dashboard
2. Выберите проект
3. Нажмите **"Deployments"** в левом меню
4. Нажмите на последний деплой (самый верхний)
5. Нажмите вкладку **"Logs"**

Это самый надёжный способ увидеть все логи выполнения.

---

## 🆘 Если всё равно не можете найти

1. **Проверьте права доступа** — убедитесь, что вы вошли в правильный аккаунт
2. **Используйте поиск** — в Vercel Dashboard есть поиск, введите "logs" или "логи"
3. **Проверьте версию Vercel** — интерфейс может отличаться в зависимости от плана

Если ничего не помогает, используйте альтернативные способы проверки через API endpoints, описанные выше.
