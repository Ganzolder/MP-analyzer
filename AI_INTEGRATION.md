# Интеграция AI для анализа отчётов

## Обзор

Проект поддерживает интеграцию с AI провайдерами (z.ai GLM-4.7, OpenAI, Anthropic) для генерации расширенных рекомендаций на основе анализа отчётов Ozon.

## Настройка

### 1. Получение API ключа

**z.ai GLM-4.7 (рекомендуется):**
1. Зарегистрируйтесь на [z.ai](https://z.ai)
2. Перейдите в раздел API Keys
3. Создайте новый ключ
4. Скопируйте ключ

**OpenAI (альтернатива):**
1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com)
2. Перейдите в раздел API Keys
3. Создайте новый ключ
4. Скопируйте ключ (начинается с `sk-`)

**Anthropic (альтернатива):**
1. Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com)
2. Создайте API ключ
3. Скопируйте ключ

### 2. Настройка переменных окружения

Создайте файл `.env.local` в корне проекта:

```bash
# z.ai GLM-4.7 (рекомендуется)
ZAI_API_KEY="your-zai-api-key-here"

# Или OpenAI
OPENAI_API_KEY="sk-your-key-here"

# Или Anthropic
ANTHROPIC_API_KEY="your-key-here"
```

### 3. Перезапуск сервера

После добавления ключа перезапустите Next.js сервер:

```bash
npm run dev
```

## Использование

### В интерфейсе

1. Загрузите файл(ы) отчёта Ozon
2. Включите переключатель "AI анализ и рекомендации"
3. Нажмите "Начать анализ"
4. AI проанализирует данные и добавит расширенные рекомендации

### Программно

```typescript
import { analyzeReport } from "@/lib/analysis";

const result = await analyzeReport(
  file,
  fileName,
  costData,
  true // useAI = true
);
```

## Что делает AI

1. **Анализирует данные отчёта:**
   - Сводные метрики (выручка, начисления, заказы)
   - Топ товары
   - Проблемные зоны
   - Структура затрат

2. **Генерирует рекомендации:**
   - Персонализированные советы по улучшению показателей
   - Приоритизация по потенциальному эффекту
   - Конкретные шаги для внедрения

3. **Дополнительные инсайты:**
   - Анализ трендов
   - Выявление скрытых проблем
   - Рекомендации по оптимизации

## API Endpoint

### POST `/api/ai/analyze`

Анализ данных с помощью AI (можно использовать отдельно).

**Request:**
```json
{
  "analysisData": {
    "summary": { ... },
    "topProducts": [ ... ],
    "problems": [ ... ],
    "costBreakdown": { ... }
  },
  "customPrompt": "Дополнительные инструкции (опционально)",
  "provider": "openai" // или "anthropic"
}
```

**Response:**
```json
{
  "recommendations": [
    {
      "id": "ai_rec_1",
      "type": "strategy",
      "priority": "high",
      "title": "Рекомендация",
      "description": "Описание",
      "impact": "Ожидаемый эффект",
      "actions": ["Шаг 1", "Шаг 2"]
    }
  ],
  "insights": "Дополнительные инсайты",
  "summary": "Краткое резюме"
}
```

## Стоимость

- **z.ai GLM-4.7:** Coding Plan ~$3/месяц + тарификация API (обычно дешевле OpenAI)
- **OpenAI GPT-4 Turbo:** ~$0.01-0.03 за анализ (зависит от размера данных)
- **Anthropic Claude:** ~$0.015-0.045 за анализ

Рекомендуется использовать для важных анализов, где нужны глубокие инсайты.

## Безопасность

- API ключи хранятся только на сервере (в `.env.local`)
- Данные отправляются только выбранному провайдеру
- Можно использовать локальные модели (требует настройки)

## Отключение AI

Если AI не настроен или не нужен:
- Просто не включайте переключатель "AI анализ"
- Система будет использовать стандартные рекомендации на основе правил

## Устранение проблем

### "API ключ не найден"
- Проверьте, что ключ добавлен в `.env.local` (для z.ai используйте `ZAI_API_KEY`)
- Убедитесь, что сервер перезапущен после добавления ключа
- Проверьте правильность ключа (без пробелов, кавычек)

### "Ошибка при анализе с помощью AI"
- Проверьте баланс на аккаунте провайдера
- Убедитесь, что ключ имеет права на использование API
- Проверьте логи сервера для деталей ошибки

### AI не генерирует рекомендации
- Убедитесь, что переключатель включен
- Проверьте, что данные анализа не пустые
- Попробуйте другой провайдер (если настроен)
