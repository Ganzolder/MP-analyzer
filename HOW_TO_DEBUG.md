# Как посмотреть логи отладки

## 1. Консоль браузера (основной способ)

1. Откройте приложение в браузере (обычно `http://localhost:3000`)
2. Нажмите **F12** (или правой кнопкой мыши → "Проверить элемент" / "Inspect")
3. Перейдите на вкладку **Console**
4. Запустите анализ файла
5. **Все логи теперь выводятся автоматически с цветным форматированием!**

### Что вы увидите в логах:

#### ✅ Начало анализа:
- `[Analysis]` Начало анализа файла — имя и размер файла
- `[Converter]` XLSX → XLS конвертация — если файл XLSX

#### ✅ Парсинг и декодирование:
- `[Parser]` Файл распарсен — количество строк, источник данных
- `[Decoder]` Примеры декодирования KOI-7 — первые 5 строк с декодированием

#### ✅ Обработка данных:
- `[Aggregator]` Заказы агрегированы — количество заказов
- `[Products]` Метрики товаров рассчитаны — статистика по товарам
- `[Products]` Топ-5 товаров по прибыли — детальная информация

#### ✅ Итоги:
- `[Summary]` Сводка рассчитана — выручка, выплата, заказы
- `[Analysis]` Анализ завершён — время выполнения

#### ⚠️ Предупреждения:
- `[Products]` Найдены товары без названий — если есть проблемы с декодированием
- `[Converter]` Ошибки конвертации — если что-то пошло не так

#### ❌ Ошибки:
- `[Converter]` Ошибка конвертации — детали ошибки
- `[API]` Ошибки API — проблемы на сервере

## 2. Терминал (сервер Next.js)

В терминале, где запущен `npm run dev`, будут логи сервера:

```
[API] Analyzing file: ...
[API] File extension: XLSX (will be converted)
[Analyzer] Converted XLSX to XLS with KOI-7 decoding
[Analyzer] Parsed 9403 rows
[Analyzer] File was converted: true
[Analyzer] First 5 rows with product names: ...
[API] Analysis complete. Top products count: ...
```

## 3. Проверка данных в Network

1. Откройте DevTools (F12)
2. Перейдите на вкладку **Network**
3. Запустите анализ
4. Найдите запрос к `/api/analyze`
5. Откройте его → вкладка **Response**
6. Проверьте поле `topProducts` - есть ли там данные

## 4. Проверка в компоненте

Если данные приходят, но не отображаются, проверьте:
- Вкладка **React DevTools** (если установлено расширение)
- Или добавьте `console.log` в компонент `app/analysis/[id]/page.tsx`:

```typescript
console.log('Top products data:', topProducts);
```

## Быстрая проверка

Откройте консоль браузера (F12) и выполните:

```javascript
// Проверить данные в store
localStorage.getItem('analysis-store')
```

Или просто запустите анализ и смотрите логи в консоли браузера - там будет вся информация о декодировании и обработке данных.
